# Maeve Clarke: maps & cartography

My portfolio site, hosted on GitHub Pages: https://dev-lizard.github.io/

## Pages

- `index.html`: Maps gallery (static maps open full size; interactive maps open their link)
- `projects.html` / `project.html?id=…`: project write-ups
- `about.html`: bio and contact (edit this file directly)
- `admin.html`: private editor, not linked from the site

## Adding and reordering content

Go to https://dev-lizard.github.io/admin.html and connect with a GitHub
fine-grained token (only this repo, **Contents: Read and write**). From there you can:

- drop in images (a thumbnail is made automatically)
- edit titles, captions, links and write-ups
- drag to reorder, hide or delete items
- click **Save to site**: changes are committed here, and the site updates in about a minute

Content lives in `data/maps.json` and `data/projects.json`, and images in
`images/`. You can also edit those files by hand on GitHub.
